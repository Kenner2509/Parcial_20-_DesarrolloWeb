# Panel de resultados de fútbol

Aplicación web en React para registrar resultados de un torneo aficionado y ver la tabla de posiciones actualizada. Sin backend: los datos viven en memoria mientras la app está abierta (al recargar la página se reinician).

## Cómo ejecutarla

Requisitos: [Node.js](https://nodejs.org) 18 o superior.

```bash
npm install
npm run dev
```

Abre la dirección que aparece en la terminal (normalmente http://localhost:5173).
